# Visual Defect: Raw Tailwind Layout Classes in Home.tsx

## Visual Defect Description
The `Home` page (`src/pages/Home.tsx`) relies heavily on raw Tailwind CSS layout utility classes directly in its TSX structure. The project strictly prohibits the use of layout classes such as `flex`, `flex-col`, `gap-*`, `space-y-*`, `grid`, and hardcoded spacing utilities like `px-*` and `py-*` directly in the `className` attribute. Developers must use custom structural primitive components (like `<Stack>` and `<Box>`) to enforce design system compliance and centralized styling logic.

## Current Visual Behavior
The page constructs its layout using raw utilities:
- `className="space-y-8 max-w-6xl mx-auto px-4 sm:px-6 lg:px-8 py-6 sm:py-8"` on the main wrapper.
- `className="flex flex-col lg:flex-row lg:items-center justify-between gap-6 pb-6 border-b border-line/80"` on the hero CTA section.
- `className="flex flex-col sm:flex-row lg:flex-col xl:flex-row items-stretch gap-3 shrink-0 lg:w-72 xl:w-auto"` on the action buttons.
- `className="grid grid-cols-1 md:grid-cols-3 gap-6 lg:gap-8 pt-2"` for the featured cards layout.
- `className="flex gap-3.5 items-start"` for feature callouts.

These classes bypass the `sanitizeClassName` enforcement found in `<Box>` and fail to utilize the semantic layout hierarchy of `<Stack>`.

## Expected Visual Behavior
The page should maintain its precise visual presentation while being refactored to utilize semantic primitives.
- Replace `<main className="space-y-8 max-w-6xl mx-auto px-4 ... py-6 ...">` with `<Box as="main" className="max-w-6xl mx-auto" px={4} py={6}>` (or appropriately handle responsive breakpoints by passing them safely).
- Replace `flex flex-col lg:flex-row` wrappers with `<Stack direction="col" className="lg:flex-row">` to abstract base flexbox logic.
- Replace inner `div` containers wrapping grouped items with `<Stack>` or `<Box>` where appropriate to align with the architectural pattern required by `AGENTS.md` and repository norms.

## Responsive & Theme Impact
- **Responsive Impact:** Direct translation requires care. Tailwind responsive variants (like `sm:px-6`, `lg:flex-row`) might need to be passed through the `className` prop of `Box` or `Stack` if the primitive components do not natively support responsive props for properties like `direction` or `px`.
- **Theme Impact:** No changes to colors, borders, or backgrounds. Purely structural.

## Accessibility Considerations
- Make use of the `as` prop on `Box` (e.g., `<Box as="section">`, `<Box as="main">`) to preserve semantic landmarks for screen readers.

## Acceptance Criteria
- All occurrences of raw `flex`, `grid`, and raw spacing/dimension utility classes in `src/pages/Home.tsx` are abstracted using `Box` and `Stack`.
- The layout remains exactly identical across mobile, tablet, and desktop breakpoints.
- The `Box` and `Stack` components are correctly imported from `src/components/layout/`.
